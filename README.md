# 🤖 AI Code Reviewer

An AI-powered Python Code Reviewer that helps developers improve their code using Google's Gemini API.

## 📌 Project Overview
AI Code Reviewer is a web-based application that analyzes source code and provides instant feedback. It identifies bugs, suggests improvements, analyzes time and space complexity, and generates an improved version of the code.

## 🎯 Problem Statement
Developers often spend a lot of time finding bugs, improving code quality, and understanding code complexity. This project helps automate these tasks using AI.

## ✨ Features
- User Registration and Login
- Secure Password Hashing
- AI-Based Code Review
- Bug Detection
- Code Improvement Suggestions
- Time and Space Complexity Analysis
- Code Quality Score
- Before and After Code Comparison
- Review History

## 🛠️ Technologies Used
- Python
- Streamlit
- Google Gemini API
- SQLite
- HTML/CSS
- Git and GitHub

## ⚙️ Project Workflow
1. User registers or logs in.
2. User selects a programming language.
3. User pastes code into the editor.
4. Gemini API analyzes the code.
5. The application displays bugs and improvements.
6. Complexity analysis and code score are generated.
7. Users can view previous code reviews.

## 🏗️ Project Architecture
User Interface → Authentication → Code Reviewer → Gemini API → Static Analysis → Results Dashboard → SQLite Review History

## 🚀 Future Scope
- Support for more programming languages.
- Advanced security and performance analysis.
- Code review export as PDF.
- More detailed code optimization suggestions.
